<task type="checkpoint:human-verify" gate="blocking">
  <name>Task 2: Human verify Phase 02 on physical iOS 26+ device</name>
  <what-built>
The complete Phase 02 app-selection flow:
- Re-localized empty-state Home (Polish: "Jeszcze żadnych wrogów" + "Wybierz aplikacje do blokady" CTA).
- `FamilyActivityPicker` sheet presented via HomeViewModel Destination (Wzorzec A).
- Persistence of selected app/category/webDomain tokens to `blocklists.json` in the App Group container (`group.com.kksw.DeluluDetox`) via atomic JSON writes.
- `BlockedView` with three fixed-order sections (Aplikacje / Kategorie / Strony www), full-swipe-to-delete, and bottom-safe-area "Zmień wybór" CTA.
- `AppRootViewModel.refreshStatus()` also fires `ReconcileBlocklistUseCase` on `scenePhase == .active`.
- Error alert shown on update failure.
  </what-built>
  <how-to-verify>
**Prerequisites:**
1. You have a physical iPhone running iOS 26 or later paired to this Mac.
2. The bundle ID `com.kksw.DeluluDetox` has (development) `family-controls` entitlement — already present from Phase 1 (CLAUDE.md line "App Group entitlement already set on all 4 targets").
3. The device already granted Screen Time (individual) authorization during Phase 1 human-verify. If not, go through Phase 1 onboarding first.

**Build + deploy:**
4. In Xcode, select your physical device as the run destination.
5. Product → Run. Confirm the app launches past Onboarding into Home.

**Walkthrough — empty state (SEL-01 / SEL-02 / SEL-03):**
6. On Home you should see the Polish empty hero: large title "DeluluDetox", `apps.iphone` SF Symbol, heading **"Jeszcze żadnych wrogów"**, body **"Wybierz aplikacje, które kradną Ci czas. Resztą zajmie się DeluluDetox."**, and a full-width accent-coloured CTA **"Wybierz aplikacje do blokady"**.
7. Tap the CTA. A system sheet opens showing Apple's `FamilyActivityPicker` with three tabs: **Apps**, **Categories**, **Websites**.
8. Pick at least **2 individual apps** (e.g., Safari, Instagram) — note this exercises SEL-01.
9. Switch to **Categories**, pick at least **1 category** (e.g., Social) — SEL-02.
10. Switch to **Websites**, add **1 website** (e.g., `reddit.com`) — SEL-03.
11. Tap **"Gotowe"** in the top-right toolbar. Sheet dismisses.

**Expected after picker dismiss:**
12. Home re-renders as `BlockedView` (not the empty hero). Navigation large title changes to **"Zablokowane"**.
13. You see 3 sections in this exact order: **Aplikacje** (your 2 apps), **Kategorie** (your 1 category), **Strony www** (your 1 domain).
14. Each row shows the Apple-rendered `Label(token)` — native app icon + name, native category name, native domain name. No custom text / icon.
15. Bottom safe-area inset shows the primary CTA **"Zmień wybór"** — same accent colour + 50pt height + 12pt corners as Phase 1 primary buttons.

**Walkthrough — swipe-to-delete:**
16. Swipe any row left slowly → reveal the red **"Usuń"** destructive button. Tap it. The row animates out. (partial-swipe path)
17. Swipe another row left fully → the row disappears immediately with no confirm dialog (full-swipe path, per UI-SPEC).
18. Confirm the sections update: if a section is now empty, the entire Section disappears.

**Walkthrough — persistence (SEL-04):**
19. Press Home button (or swipe up) to background the app.
20. Swipe up from the app switcher to fully quit the app.
21. Relaunch DeluluDetox from the home screen.
22. Expected: the `BlockedView` immediately shows the remaining records (whatever survived your deletes in steps 16/17). **No data loss.**

**Walkthrough — scenePhase reconcile (SEL-05):**
23. Background the app (do NOT force-quit). Wait ~2 seconds.
24. Foreground it. Observe no visible change (reconcile is silent — this is expected per UI-SPEC §Reconciliation state).
25. In Xcode, open the Console / Logger stream for subsystem `com.kksw.DeluluDetox` and filter category `AppRoot`. On every scenePhase → active transition, a log line for reconcile should appear (either an info line confirming write, or an error log if a failure path hit).

**Walkthrough — "Zmień wybór" round-trip:**
26. Tap **"Zmień wybór"** on BlockedView. The picker opens again.
27. Confirm your existing selections are checkmarked (pre-seeded from `Blocklist.lastSelection`). This is SEL-05 identity preservation: existing records keep their UUIDs; the Apple picker shows previous picks.
28. Uncheck one app, add a different one, tap **"Gotowe"**.
29. Back in BlockedView: the old app is gone, the new app is present. Existing untouched rows still have their original order (new records append at the end of their section — verify no duplicate UUIDs).

**Walkthrough — empty state round-trip:**
30. Delete all remaining rows via swipe.
31. The view transitions back to the Polish empty hero with a crossfade (0.35s animation per UI-SPEC §Transitions).
32. Tap CTA again → picker opens with **zero** pre-selections (selection has been cleared by the deletes).

**Error path (optional, harder to trigger on device):**
33. If you want to verify the error alert, temporarily revoke Screen Time authorization in iOS Settings → Screen Time → Apps & Websites Activity → disable. On next foreground, AppRoot's scenePhase handler should route you to the Denial screen (Phase 01.1 behaviour). This is tangential to Phase 02 but confirms the auth guard still fires.

**Report one of:**
- **"approved"** — every step above matched expectations.
- A specific issue: step number, what you observed, and what you expected. Claude will then open a revision cycle (`/gsd-plan-phase 02 --gaps`).
