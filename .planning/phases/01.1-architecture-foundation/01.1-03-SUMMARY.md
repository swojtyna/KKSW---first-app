# Phase 01.1 Plan 03: Onboarding/Denial/Home VM Feature-First + @LazyInjected Migration Summary

**Three of four features (Onboarding, Denial, Home) migrated to feature-first layout; OnboardingViewModel + DenialViewModel adopt `@ObservationIgnored @LazyInjected private var requestAuth` over `DIContainer.shared` with bezargumentowy `init()`; HomeViewModel moved without functional changes (D-15); `DenialInjection` + `HomeInjection` no-op for architectural symmetry; `DependencyContainer` shim produces VMs via `()` and wires `onAuthorized` post-init; `DeluluDetoxApp.init()` transitionally bootstraps `OnboardingInjection.register(in: DIContainer.shared)`; Swift 6.2 cascade concurrency errors spot-fixed with `@MainActor` on `AppRootViewModel.init/checkAuthorization` + `@MainActor` on `AppRootViewModelTests`; build green, 8/8 tests passing.**

## Accomplishments

- Three features (Onboarding, Denial, Home) migrated to feature-first Simple variant per `feature-structure/GUIDE.md`. Struktura `Features/<Feature>/{ViewModel, View, Injection}/` spójna dla wszystkich trzech. Onboarding zachowuje dodatkowo `Repository/` + `UseCase/` z Wave 2.
- `OnboardingViewModel` i `DenialViewModel` przełączone na property wrapper: `@ObservationIgnored @LazyInjected private var requestAuth` + bezargumentowy `init()`. Dekoracje klasy: `@MainActor @Observable final class … : @unchecked Sendable` (kompozycja wymagana przez `@LazyInjected` nad `DIContainer.shared` per dependency-injection GUIDE).
- D-10 ordering ensured: `@ObservationIgnored` poprzedza `@LazyInjected` w obu VM (grep `@ObservationIgnored[\s\n]+@LazyInjected` zwraca ≥ 1 dla każdego VM).
- Transitional `var onAuthorized: (() -> Void)?` pozostaje na obu VM — AppRootView nadal wiresuje callback do `checkAuthorization()` przez `DependencyContainer.makeOnboardingViewModel(onAuthorized:)` / `makeDenialViewModel(onAuthorized:)`. Callback znika w Wave 4 (`01.1-04`), gdy AppRootVM przechodzi na Combine publisher (D-11).
- `HomeViewModel` przeniesiony bez zmian funkcjonalnych (D-15 — HomeVM w Phase 01.1 pozostaje bez UC, Phase 2 wprowadzi pierwszy).
- `DenialInjection` + `HomeInjection` istnieją jako no-op `enum … { static func register(in container: DIContainer) }` — Denial konsumuje `RequestScreenTimeAuthUseCase` z Onboarding registration (D-17), Home nie ma UC w 01.1 (D-15). Pliki istnieją dla architektonicznej symetrii i przyszłego rozrostu.
- `DependencyContainer` shim: `makeOnboardingViewModel` / `makeDenialViewModel` tworzą VM przez `()` + przypisują `onAuthorized` post-init. `makeAppRootViewModel` + te dwie factory oznaczone `@MainActor` (bo VMs są `@MainActor`).
- `DeluluDetoxApp.init()` tymczasowo wywołuje `OnboardingInjection.register(in: DIContainer.shared)` — bez tego runtime `grantAccessTapped()` fatalError'owałby (pusty DIContainer). Wave 4 doda `HomeInjection.register` + `DenialInjection.register` + `RootInjection.register`, Wave 5 usunie `DependencyContainer`.
- `AppRootViewModel.init(container:)` + `checkAuthorization()` dostały `@MainActor` spot-fix — wymagane przez `@MainActor` VM factories. Pełna `@MainActor` adopcja + `@State private var model` child-owned VM lifecycle w Wave 4.
- `OnboardingViewModelTests` przestawione na DIContainer mocking: `setUp` robi `DIContainer.shared.reset()` + rejestruje `MockScreenTimeAuthRepository` + real `RequestScreenTimeAuthUseCaseImpl`. Testy używają bezargumentowego `OnboardingViewModel()` i nadal sprawdzają `onAuthorized` callback (TRANSITIONAL — zmiana na Combine subscription w Wave 5).
- `AppRootViewModelTests` dostało `@MainActor` na klasie (Rule 3 auto-fix: blocking cascade concurrency error po spot-fixie Task 2). Kontrakt Phase 1 (DependencyContainer + mockRepo) zachowany — pełny rewrite do DIContainer setUp zaplanowany na Wave 5.
