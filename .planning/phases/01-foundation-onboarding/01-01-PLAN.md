    }

    import Observation

    struct DependencyContainer {
        let screenTimeAuthRepository: ScreenTimeAuthRepository = ScreenTimeAuthRepositoryImpl()

        func makeRequestScreenTimeAuthUseCase() -> RequestScreenTimeAuthUseCase {
            RequestScreenTimeAuthUseCaseImpl(repository: screenTimeAuthRepository)

        func makeAppRootViewModel() -> AppRootViewModel {

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| App -> AuthorizationCenter | System API call; untrusted result (user can deny) |
| App <-> App Group | Shared container between app and extensions; only app's own extensions in group |
| Extension -> iOS | Extension loaded by iOS system; must have correct identifiers |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Elevation of Privilege | AuthorizationCenter | mitigate | Check `authorizationStatus` on every `scenePhase == .active` in AppRootViewModel (Plan 02); hard gate prevents app usage without Screen Time permission (D-04) |
| T-01-02 | Denial of Service | Extension targets | mitigate | Verify correct NSExtensionPointIdentifier per extension type in project.yml; validate bundle ID prefix `com.kksw.DeluluDetox.*` for all extensions |
| T-01-03 | Information Disclosure | App Group container | accept | Only app's own extensions share the group; no sensitive user data stored in Phase 1; no PII at all |
| T-01-04 | Tampering | project.yml entitlements | mitigate | Single `.entitlements` file per target generated by XcodeGen; no split Debug/Release entitlements (Pitfall 4 from RESEARCH.md) |
</threat_model>
