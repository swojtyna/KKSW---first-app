  <what-built>
The complete Phase 3 quick-session flow, end to end:
- New toolbar `play.circle.fill` button on Home (disabled while the blocklist is empty) → opens `SessionStartView`.
- `SessionStartView` — 4 preset chips (15/30/60/90 min) + custom wheel picker (5 min–8 h) + primary "Uruchom sesję" CTA.
- `StartSessionUseCase` atomic start: persists SessionRecord, applies `ManagedSettingsStore(named: "deluludetox.session")` shield across apps + categories + webDomains, turns on `requireAutomaticDateAndTime` + `denyAppRemoval`, registers a non-repeating `DeviceActivitySchedule` ending at `plannedEndAt`.
- Automatic push to `CountdownView` via HomeViewModel's `ObserveActiveSessionUseCase` subscription — progress ring + monospaced digits + sarcastic caption.
- "Zakończ wcześniej" button + `.confirmationDialog` — confirming calls `EndSessionUseCase(outcome: .cancelledByUser)`.
- DAM extension `intervalDidEnd` clears the shared ManagedSettingsStore, writes `session_finalize_marker.json`, posts a Darwin notification.
- `AppRootViewModel.refreshStatus()` on `scenePhase == .active` consumes the marker, self-heals expired sessions, and detects Screen Time revocation.
- `SessionSuccessView` shown once per completed session (UserDefaults flag).
- `sessions.json` persists all sessions with their outcomes (completed / cancelled_by_user / broken_by_revoke).

### Prerequisites

1. Physical iPhone running **iOS 26 or later** paired to this Mac. (Simulator cannot enforce Screen Time shields or run DAM extensions.)
2. Bundle ID `com.kksw.DeluluDetox` has the dev `family-controls` entitlement (set up in Phase 1).
3. Screen Time (individual) authorization granted (from Phase 1 UAT).
4. Phase 2 complete: at least **2 apps** already in the blocklist. If not, do Phase 2's "Wybierz aplikacje do blokady" step first — Phase 3 cannot start a session with an empty list (CONTEXT §D-06).
5. Note the deviation recorded in Phase 02 SUMMARYs: on this host, the iPhone 17 simulator UUID is `6D73311F-3541-4B74-92E8-8014FABC3329` (not the CLAUDE.md canonical `C958163F-...`). Device UUID will differ — pick your actual device in Xcode Run scheme.

### Build + deploy

6. In Xcode, select your physical device as the run destination.
7. Product → Run. Confirm the app launches past Onboarding into Home (or directly to Home if auth already granted).
8. On Home, confirm the top-right toolbar shows a filled purple `play.circle.fill` button. It should be **enabled** (not greyed) if your blocklist has records.

### Walkthrough A — 15-minute preset happy path (QSN-01 + QSN-03 + QSN-04 + QSN-06)

9. Tap the toolbar `play.circle.fill` button. `SessionStartView` pushes with title "Nowa sesja".
10. You should see:
    - Header "Na ile odłączamy świat?" + subtitle "Wybierz preset albo ustaw własny czas. Kończy się sam — nie musisz patrzeć."
    - A row of four chips: **15 min**, **30 min**, **60 min**, **90 min**. By default **30 min** is highlighted (purple background, white text).
    - Below that, a "Albo własny czas" row with a circle toggle and label like "30 min" or "0 h 30 min".
    - Bottom CTA "Uruchom sesję".
11. Tap the **15 min** chip — it gets the highlighted state, others are de-selected.
12. Tap **"Uruchom sesję"**. Expected:
    - The button briefly shows "Startuję…".
    - iOS may prompt for Screen Time confirmation (rare after first-time setup — if it does, accept).
    - The app pushes automatically to `CountdownView` (title "Sesja aktywna").
13. On CountdownView, confirm:
    - A large circular progress ring, drained a fraction.
    - Monospaced digits like **15:00** (MM:SS — because duration < 1 h). They tick down every second.
    - Caption "Pij wodę, oddychaj. Wyłączone aplikacje same się nie odblokują."
    - Bottom destructive button "Zakończ wcześniej" (red-tinted bordered button).
14. **Leave the DeluluDetox app.** Press the Home bar (swipe up) or go to the iOS Home screen.
15. Tap on one of the apps you had in your blocklist (e.g., Instagram). Expected: Apple's default system shield overlay appears — the app is blocked (QSN-03).
16. Come back to DeluluDetox. Countdown is still running; remaining time has decreased.

### Walkthrough B — Let the 15-min timer run down (QSN-06)

17. Put your phone aside for **~15 minutes**. You can keep the device awake or let it sleep. Do NOT kill the DeluluDetox app (swipe-up-and-flick it away).
18. After the timer should be near zero, reopen the DeluluDetox app. Expected within ~10 seconds:
    - The CountdownView disappears and Home re-renders (because `active_session.json` is gone — consumed by AppRootViewModel self-heal or marker reconciliation).
    - A **success sheet** slides up with:
      - Large ⭐ or sparkles icon.
      - "Wytrzymałeś 15 minut" title.
      - One sarcastic caption (e.g. "Świat się nie zawalił." — any of the 4 caption strings is acceptable).
      - A "Dzięki, wiem" CTA.
19. Tap "Dzięki, wiem" (or tap anywhere on the screen). Sheet dismisses. Home is idle.
20. Leave Home and try to open one of the blocked apps again. Expected: the app opens normally — the shield is cleared (QSN-06).

### Walkthrough C — Early-end with confirm dialog (QSN-05)

21. Start a fresh session, this time using the **30-min** preset (default).
22. On CountdownView, tap **"Zakończ wcześniej"**.
23. Confirmation dialog appears:
    - Title "Zakończyć wcześniej?"
    - Message "Timer ma jeszcze XX:XX. Jesteś pewien?"
    - Destructive button "Tak, kończę wcześniej".
    - Cancel button "Nie, wytrzymam".
24. Tap **"Nie, wytrzymam"** — dialog dismisses, countdown continues (QSN-05 friction works: the exit requires a deliberate confirm).
25. Tap **"Zakończ wcześniej"** again, then tap **"Tak, kończę wcześniej"**.
26. Expected: CountdownView pops, Home appears. NO success screen (cancelled sessions don't celebrate). Blocked apps are accessible again.

### Walkthrough D — Custom duration (QSN-02)

27. Tap the toolbar play button again.
28. Tap the "Ustaw samodzielnie" row — its checkmark icon turns purple, the preset chips de-select.
29. The `DatePicker(.hourAndMinute)` wheel appears inline. Dial it to **0 h 6 min** (or the lowest the wheel lets you). Expected: 6 min > 5 min floor, so Start CTA stays enabled.
30. Try to dial to **0 h 4 min**. Expected: VM clamps to 5 min (you should see the "Ustaw samodzielnie" label update — note this behavior is approximate; the clamp happens at resolve time, so the displayed value may briefly show the dialed value).
31. Set duration back to **0 h 6 min** and tap "Uruchom sesję". Confirm the countdown shows **06:00**.
32. Let it finish or cancel early — doesn't matter for this walkthrough; just confirm custom duration works.

### Walkthrough E — Revocation detection (QSN-05)

33. Start a fresh 15-min session.
34. Open iOS **Settings → Screen Time → Apps With Screen Time Access**. (You may need to scroll to find DeluluDetox.)
35. Tap DeluluDetox and toggle OFF "Allow Access" — revoking Screen Time permission mid-session.
36. Return to DeluluDetox. Expected within ~10 seconds:
    - The session is finalized with outcome `broken_by_revoke`.
    - You're bounced to the DenialView or Onboarding (destination transitions when `AuthorizationCenter.shared.authorizationStatus` is no longer `.approved`).
    - No success sheet (broken sessions don't celebrate).
37. Re-grant permission via Settings → Screen Time (if you want to keep testing) and reopen the app — onboarding should route back to Home.

### Walkthrough F — Empty-blocklist gate (CONTEXT §D-06)

38. From Home, tap "Zmień wybór" (or the picker CTA) and UNSELECT all apps. Save with "Gotowe".
39. Home returns to empty-state mode. The toolbar `play.circle.fill` button should be **disabled** (greyed out).
40. Tapping it does nothing (VM `canStart` is false).

### Walkthrough G — Single-session-at-a-time gate (CONTEXT §D-05)

41. This one is optional and requires quick hands. Start a 15-min session. Before it ends, kill the app (swipe up + flick away). Relaunch. You should land directly on `CountdownView` (HomeViewModel observes the active session publisher and routes automatically).
42. Confirm the timer is still counting down (shield is still enforced).

### Artifact spot-checks (optional power-user)

43. If you have a Console.app window open filtering `com.kksw.DeluluDetox`, you should see log lines from:
    - `SessionEnforcer` (`shield applied`, `shield cleared`).
    - `StartSessionUC` / `EndSessionUC`.
    - `DeviceActivityMonitorExtension.Monitor` (`intervalDidEnd`, `store cleared`, `marker written`, `darwin post`).
    - `FinalizeFromMarkerUC` / `SelfHealUC` / `DetectRevocationUC`.
44. You do NOT need to verify the `sessions.json` contents directly — its correctness is covered by unit tests.
