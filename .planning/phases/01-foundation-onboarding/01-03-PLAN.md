<task type="checkpoint:human-verify" gate="blocking">
  <what-built>
    Complete onboarding flow with 3 screens:
    1. Onboarding: "Your Phone Is Winning" + "Grant Access" button with lock.iphone SF Symbol
    2. Denial: "Nice Try" + "Let's Try Again" button with hand.raised.fill SF Symbol
    3. Home: "No Apps Blocked Yet" + "Choose Apps to Block" button with apps.iphone SF Symbol

    All screens use electric violet (#7C3AED) accent color on white background. Transitions are 0.35s opacity crossfade.
  </what-built>
  <how-to-verify>
    **On Simulator (visual verification):**
    1. Build and run the app on iPhone simulator
    2. Verify onboarding screen appears with:
       - Large lock.iphone SF Symbol in violet
       - "Your Phone Is Winning" headline in bold
       - Privacy explanation body text
       - "Grant Access" button in violet with white text
    3. Tap "Grant Access" -- button should show spinner briefly, then transition (on simulator, authorization fails silently; app may stay on onboarding or transition to denial)
    4. Check that no raw colors appear (everything should use the electric violet accent or system grays)
    5. Check that text is readable and properly centered
    6. Verify the "Choose Apps to Block" button on home screen is tappable but does nothing (Phase 2)

    **On Physical Device (optional, full flow):**
    1. Build and run on a physical iPhone with the development entitlement
    2. Tap "Grant Access" -- system Face ID/passcode prompt should appear
    3. Deny the permission -- verify "Nice Try" denial screen appears and cannot be dismissed
    4. Tap "Let's Try Again" -- system prompt should reappear
    5. Grant permission -- verify smooth transition to home screen with "No Apps Blocked Yet"
    6. Background and foreground the app -- verify it stays on home screen (authorization still valid)

    **Check these specific items:**
    - [ ] Onboarding headline reads exactly "Your Phone Is Winning"
    - [ ] Denial headline reads exactly "Nice Try"
    - [ ] Home heading reads exactly "No Apps Blocked Yet"
    - [ ] All buttons are violet with white text
    - [ ] SF Symbols are the correct ones (lock, hand, apps)
    - [ ] No navigation bar on onboarding/denial screens
    - [ ] Large title "DeluluDetox" on home screen
    - [ ] Transitions are subtle (no confetti, no bounce)
  </how-to-verify>
  <resume-signal>Type "approved" if screens look correct, or describe specific issues to fix</resume-signal>
</task>
